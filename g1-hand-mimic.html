01Perception Pipeline — 21 Landmarks to Joint Angles

◉
[ img: camera + laptop setup ]
USB webcam at eye level above the keyboard, terminal streaming live angle arrays

MediaPipe hand tracking. Each webcam frame yields 21 3D landmarks per hand at 25–30 Hz on the GPU delegate — the raw geometry the whole pipeline runs on.

Finger triplets. Each of the four fingers uses an (MCP, PIP, tip) landmark triplet; the interior angle at the PIP vertex measures curl directly.

retarget.py

# MCP, PIP, tip landmark indices per finger
_FINGER_TRIPLETS = {
    "index":  (5, 6, 8),
    "middle": (9, 10, 12),
    "ring":   (13, 14, 16),
    "pinky":  (17, 18, 20),
}

def _angle_deg(a, b, c) -> float:
    # interior angle at vertex b (degrees)
    v1, v2 = a - b, c - b
    return float(np.degrees(np.arccos(
        np.clip(np.dot(v1, v2) / (norm(v1) * norm(v2)), -1.0, 1.0)
    )))

Angle → register mapping. The interior angle maps linearly onto the Inspire's 0–1000 integer scale: ~170° fully extended → 1000, ~50° fully curled → 0.

Gesture overlay. Colored circles mark detected gestures on the fingertips — orange = fist, blue = 3-finger pinch, red = 2-finger pinch.

02Retargeting & the Thumb Problem

  • pinch detectionthumb-tip to index-tip < 0.28 palm-widths → hardware preset snap
  • thumb curlIP-joint angle (CMC→MCP→IP) — stable when thumb folds across palm
  • thumb rotationnormalized x-offset of thumb tip from index MCP / palm width
  • occlusion guardfingertip within 0.6 palm-widths of palm center → clamp to 150
  • smoothingper-DOF EMA, thumb channels get 6× wider deadband
  • hot reloadpress t → hand_mimic.yaml recalibrates live, no restart
✱
[ img: inspire RH56 on bench ]
Silver aluminum-and-silicone 5-finger hand on the bench, GX12 connector visible, fingers mid-pinch

Pinch beats geometry. All distances are divided by palm width for scale invariance; below the 0.28 threshold a calibrated hardware preset snaps the thumb to the pinch pose instantly instead of chasing noisy geometry.

Occlusion guard. Inside a fist, MediaPipe reports a false ~180° "open" angle for hidden fingertips — the guard clamps those channels to near-closed regardless of the computed angle.

state_new = α · measurement + (1 − α) · state_old

EMA smoothing with configurable per-DOF alpha kills jitter without adding visible lag; the thumb — the noisiest axis — gets the widest deadband.

Three retargeting backends: geom — fast calibrated geometric mapping (default); dex — full dex-retargeting optimizer, higher quality but slower; hybrid — geometric everywhere, with the dex optimizer overriding index and thumb only during a detected pinch.

03Serial Hardware — RS-485 to the Hand

  • protocolModbus-style register writes over RS-485 @ 115200 baud
  • adapterUSB-to-RS485 dongle (FTDI / CH340) — /dev/ttyUSB0, /dev/ttyUSB1 per hand
  • power24 V to the hand; internal firmware runs the PD servo loop per DOF
  • connectorGX12 4-pin aviation — RS-485 A+/B− plus 24 V power
  • channel order[pinky, ring, middle, index, thumb_bend, thumb_rot]

No DDS here — the hand link is completely separate from the robot body's communication stack. The host only writes angle registers; the hand's firmware closes the position loop internally.

inspire_hand.py

hand = InspireHand(port="/dev/ttyUSB0", baud=115200, hand_id=1)
hand.set_speed([2000] * 6)
hand.set_force([400] * 6)
# 6-integer angle vector → angle register writes
hand.set_angles([pinky, ring, middle, index, thumb_bend, thumb_rot], wait=False)
