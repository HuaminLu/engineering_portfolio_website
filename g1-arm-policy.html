MuJoCo Arm Policy — RL Goal-Reaching Without an IK Solver

algorithm PPO (SB3) training ~53M timesteps obs/action 24-D / 7-D deploy DDS rt/arm_sdk

A PPO agent trained in a MuJoCo simulation of the G1 solves 7-joint inverse kinematics in real time — no analytical IK solver. WASDQE keys move a red goal dot in 3D; pressing R mirrors the sim arm onto the physical robot over DDS.

  • PPO reinforcement learning agent trained over 53M timesteps in MuJoCo physics.
  • Real-time 7-DOF joint space reaching without relying on analytical inverse kinematics.
  • Hardware mirroring streams policy actions over CycloneDDS to physical G1 arm motors.

01Training Setup — PPO in MuJoCo

  • 24-D observation space encompasses joint angles, velocities, end-effector pose, and target deltas.
  • Incremental joint deltas bounded to ±0.05 rad prevent jerk and ensure smooth physical execution.
  • q (7)current joint angles (rad)
  • dq (7)current joint velocities (rad/s)
  • p_hand (3)end-effector position from forward kinematics (m)
  • p_goal (3)goal position (m)
  • Δp (3)p_goal − p_hand error vector
  • step_frac (1)episode progress ∈ [0, 1]

02Reward Design — Dense Shaping

  • Dense reward shaping combines Euclidean goal distance with regularizers for upright wrist pitch.
  • Self-collision avoidance penalty prevents damaging contact with the robot torso.

g1_arm_rl_env.py — dense reward formulation

reward = -5.0 * dist - 0.1 * norm(action)  # goal reaching + effort penalty
if dist < 0.02: reward += 1.0  # 2 cm tolerance arrival bonus

03Sim-to-Real Deployment — DDS Streaming

  • Policy inference executes at 25 Hz against the live simulation state.
  • Streaming mode broadcasts LowCmd_ packets over rt/arm_sdk to actuate the real robot.

g1_arm_policy_controller.py — inference & DDS streaming

action, _ = policy.predict(obs, deterministic=True); q += action
msg.motor_cmd[idx].q = q[i]; msg.motor_cmd[29].q = 1.0  # DDS stream
τ_applied = kp·(q_cmd − q_measured) + kd·(dq_cmd − dq_measured) + tau_ff
