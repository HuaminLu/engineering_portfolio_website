MuJoCo Arm Policy — RL Goal-Reaching Without an IK Solver

algorithm PPO (SB3) training ~53M timesteps obs/action 24-D / 7-D deploy DDS rt/arm_sdk

A PPO agent trained in a MuJoCo simulation of the G1 solves 7-joint inverse kinematics in real time — no analytical IK solver. WASDQE keys move a red goal dot in 3D; pressing R mirrors the sim arm onto the physical robot over DDS.

01Training Setup — PPO in MuJoCo

PPO via Stable-Baselines3 (MlpPolicy) across 16 parallel environments, trained for ~53 million timesteps on the G1 29-DOF MuJoCo model — waist and unused arm locked so learning focuses entirely on the 7 left-arm joints.

  • q (7)current joint angles (rad)
  • dq (7)current joint velocities (rad/s)
  • p_hand (3)end-effector position from forward kinematics (m)
  • p_goal (3)goal position (m)
  • Δp (3)p_goal − p_hand error vector
  • step_frac (1)episode progress ∈ [0, 1]

Bounded incremental actions. The policy outputs joint deltas Δq ∈ ±0.05 rad per step — not absolute angles — which caps per-timestep motion and prevents sudden jerks.

Focused observation. The 24-D observation gives the network everything it needs to close the loop: joint state, hand and goal positions, the error vector, and time remaining.

02Reward Design — Dense Shaping

g1_arm_rl_env.py

reward = -5.0 * dist - 0.1 * norm(action)
# + 1.0 if dist < 0.02 m (goal reached)
# − 1.5 * (1 − vertical_alignment)   # grasp orientation regularizer
# − 1.5 * horiz_deviation             # palm plane horizontal penalty
# − large penalty on self-collision

Distance dominates. Negative Euclidean distance to the goal (×5) drives reaching; a small action penalty (×0.1) discourages large joint motions; a +1 bonus fires when the hand comes within 2 cm.

Orientation regularizers keep the grasping axis vertical and the palm plane level for downstream manipulation. Self-collision terminates the episode at −10. The episode horizon scales with initial distance: ⌈‖Δp₀‖ / 0.05⌉ + 10 steps.

03Sim-to-Real Deployment — DDS Streaming

The controller runs policy inference at ~25 Hz against the live MuJoCo state, integrating each delta into the joint targets.

g1_arm_policy_controller.py — inference loop

obs = build_observation(q, dq, p_hand, p_goal)
action, _ = policy.predict(obs, deterministic=True)
q += action  # integrate delta
mj_forward(model, data)  # update physics + render

Pressing R streams the sim joint angles to the physical G1 as LowCmd_ packets on the rt/arm_sdk DDS topic — position targets only, with the on-board controller closing the loop.

g1_arm_policy_controller.py — robot streaming (press R)

# Builds a Unitree LowCmd_ packet for rt/arm_sdk topic
for i, joint_idx in enumerate(ARM_JOINT_INDICES):
    msg.motor_cmd[joint_idx].q   = q_target[i]   # rad
    msg.motor_cmd[joint_idx].dq  = 0.0
    msg.motor_cmd[joint_idx].tau = 0.0
    msg.motor_cmd[joint_idx].kp  = 40.0   # position gain
    msg.motor_cmd[joint_idx].kd  = 1.0    # damping
msg.motor_cmd[29].q = 1.0   # arm_sdk enable flag
# CRC checksum appended, then Write() over DDS

Each motor's controller runs a PD servo law around the streamed targets:

τ_applied = kp·(q_cmd − q_measured) + kd·(dq_cmd − dq_measured) + tau_ff
