Hand Recorder GUI — Keyframe Gesture Animator

framework Flet (Flutter) streaming 25 Hz target Inspire RH56 format YAML presets

A desktop GUI for authoring and replaying precise hand gesture animations on the Inspire hands — dial in poses with six live sliders, record takes, and combine them into finished sequences.

Phone Side · Dual Hands
PC Side · Hand Recorder GUI
Dual-Hand Keyframe Recorder GUI — Left: Dual Inspire RH56 dexterous hands responding live to dialled joint angles. Right: Flet desktop GUI streaming 6-DOF register values at 25 Hz over RS-485 serial.

01The GUI & Live Streaming

Six sliders, six DOF. Each slider maps to one joint — pinky, ring, middle, index, thumb bend, thumb rotation — and values stream to the hand at 25 Hz while adjusting, giving tactile live feedback.

Two themes. A blue/black default and a black/white mode (--theme bw) match the operator environment.

02Recording Workflow

  • RECsamples the 6-DOF pose at 25 Hz into a Take (list of frames)
  • STOPauto-smoothing applied — linear interpolation or EMA
  • COMBINEparallel merge — two selected Takes play simultaneously
  • SAVE PRESETconcatenates all items into presets/<name>/animation.yaml
  • play speedslider linearly resamples the frame timeline — 0.5× to 2×

presets/2finger_pinch/animation.yaml

# saved gesture preset — one row per 25 Hz frame
gesture: 2finger_pinch
fps: 25
frames:
  - [800, 800, 800, 800, 500, 300]
  - [820, 820, 820, 830, 480, 320]
  - ...

Playback speed resampling. The play-speed slider linearly resamples the timeline, so a 1-second recording replays cleanly at 0.5× or 2× speed.

03Gesture Library

  • 2finger_pinchthumb + index pinch
  • 3finger_pinch3-finger precision grip
  • grabfull power grasp

Serial auto-detection. scan_serial_ports() enumerates USB-serial adapters by USB VID and maps them to left/right hand sides; the mapping persists to config/serial_map.json across restarts.

Behaviors by demonstration. The intended runtime: MediaPipe classifies the hand state (pinch / grab / point) and the matching recorded animation plays back — precise, repeatable behaviors authored by demonstration, not hand-edited angle arrays.
