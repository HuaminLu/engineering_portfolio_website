WASDQE Walk — High-Level Bipedal Locomotion Teleop

plane high-level velocity RPC loop 15 Hz pulse 0.45 s tap-to-inch safety clamp 1.4 m/s / 2.0 rad/s

An always-on-top GUI that walks the bipedal G1 with the keyboard. The operator commands a body-velocity setpoint — the robot's onboard whole-body controller owns balance, gait, and leg inverse kinematics.

01High-Level Control Plane

This is the high-level control plane, in contrast to the arm projects — those stream every joint's 5 variables at low level. Here the operator never touches a joint angle: the loop sends 3 numbers and the onboard ai_sport stack does footstep planning, balance, and per-joint torque computation.

drive_loop.py

# 15 Hz drive loop — one body-velocity setpoint per tick
code = loco_client.SetVelocity(vx, vy, omega, duration=864000.0)
# vx = forward/back (m/s), vy = strafe (m/s), omega = yaw rate (rad/s)

Velocity in, gait out. The onboard whole-body controller receives the setpoint and runs its full gait pipeline — none of that is visible to this project.

WASDQE mapping. W/S drive forward/back, Q/E strafe, A/D turn — familiar game controls for precise floor-level teleop.

02Tap-to-Inch Motion Model

  • SPEED_MIN0.15 m/s — minimum tap pulse velocity
  • SPEED_MAX1.20 m/s — maximum tap pulse velocity
  • ANG_RATIO1.25 rad/s of turn per 1 m/s linear
  • PULSE_SECS0.45 s — each keypress drives one pulse, then auto-stops
  • hard clampsVMAX_LIN 1.4 m/s · VMAX_ANG 2.0 rad/s

Bounded pulses, never momentum. Each keypress fires one velocity pulse for 0.45 s, then auto-stops — speed never accumulates; re-pressing re-fires the same pulse. The SPEED slider scales pulse magnitude, SHIFT boosts 1.6×.

Layered safety. An ENABLE switch gates all motion; SPACE stops immediately, Z damps every joint compliant, ESC cuts to zero torque.

fsm_safety.py

bot.SetFsmId(200)       # engage gait FSM state 200 (walking mode)
bot.SetBalanceMode(1)   # continuous gait balance (vs. static hold)
bot.StopMove()          # SPACE key → immediate stop
bot.Damp()              # Z key → all joints go compliant (fall gently)
bot.ZeroTorque()        # ESC → all motors off

03Root-Causing Error 3102

Every walk command failed with error 3102 (RPC_ERR_CLIENT_SEND). Root cause: firmware ai_sport ≥ 8.2.0.0 renamed the locomotion RPC service "loco" → "sport", while the vendored SDK still hardcoded "loco". A two-line patch fixes it.

service_name_fix.py

import unitree_sdk2py.g1.loco.g1_loco_api as _loco_api
_loco_api.LOCO_SERVICE_NAME = "sport"   # override before LocoClient.__init__()

NIC auto-detection. _resolve_g1_iface() scans all network interfaces via Linux's SIOCGIFADDR ioctl and returns the one holding a 192.168.123.x address — the G1's wired Ethernet bus, with no hardcoded interface names.

Noise filter. The SDK's lease-renewal thread spams harmless 3102 errors every second; a _NoiseFilter stdout wrapper intercepts those lines by pattern before they reach the terminal.
