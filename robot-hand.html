10-DOF Anthropomorphic Dexterous Hand

actuators MG90S × 10 controller ESP32 Mini + PCA9685 servo rail 6V @ 10A CAD SolidWorks surfacing

A fully functional 10-degree-of-freedom robotic hand. Advanced CAD surfacing packs 10 micro-servos into an ergonomic palm; the power system survives all 10 stalling at once.

  • Engineered a high-transient power architecture that sustains 10 A simultaneous stall current across 10 independent servos without a single MCU brownout.
  • Eliminated PWM jitter by offloading 50 Hz timing to a dedicated I²C hardware driver — RTOS context switching and WiFi tasks never touch the signal.
  • Packed 10 actuators into an anthropomorphic palm using advanced boundary surfacing and surface lofts in SolidWorks, with zero mechanical interference.

02Electrical — Transient-Safe Power

  • supply12V 10A DC
  • servo rail6V via XL4015 CC/CV buck converter
  • worst-case load10 servos stalled ≈ 10 A
  • protection10A automotive blade fuse on 12V input
  • bulk capacitance4700 µF electrolytic across 6V rail
  • decoupling0.1 µF ceramics for switching noise

Transient suppression. Servos are inductive loads — a sudden grip pulls a current spike that would sag the rail. The 4700 µF bulk cap acts as a local energy reservoir, absorbing back-EMF and feeding instant current.

Logic isolation. The PCA9685 physically separates 3.3V logic power (VCC, from the ESP32) from 6V actuator power (V+, from the buck). A mechanical stall can never brown out the MCU or corrupt the I²C bus.

03Embedded Control — I²C Offloading

The ESP32's RTOS context switching and WiFi tasks would jitter software PWM. All 10 channels of 50 Hz PWM generation are offloaded to the PCA9685 over I²C — the driver holds pulses in hardware.

hand_control.cpp

#include <Wire.h>
#include <Adafruit_PWMServoDriver.h>

Adafruit_PWMServoDriver pwm = Adafruit_PWMServoDriver(0x40);

#define SERVO_FREQ 50   // standard analog servo frequency (Hz)
#define SERVOMIN   150  // pulse count for 0°   (of 4096)
#define SERVOMAX   600  // pulse count for 180° (of 4096)

void setup() {
  Wire.begin(21, 22);              // ESP32 I2C: SDA=21, SCL=22
  pwm.begin();
  pwm.setOscillatorFrequency(27000000);
  pwm.setPWMFreq(SERVO_FREQ);       // hardware-timed 50 Hz
}

void actuateFinger(uint8_t fingerID, uint16_t angle) {
  uint16_t pulse = map(angle, 0, 180, SERVOMIN, SERVOMAX);
  pwm.setPWM(fingerID, 0, pulse);   // jitter-free hardware PWM
}
